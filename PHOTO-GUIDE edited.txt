# My Reverso Story — Photo Guide

## How to add a photo (no code editing)

1. Make a folder called **`images`** next to the HTML files.
2. Save your photo as a **`.jpg`** named exactly after the slot ID.
3. Refresh. The placeholder is replaced automatically.

```
my-reverso-story.html
reverso-history.html
reverso-models.html
reverso-calibres.html
reverso-collection.html
reverso-styles.css
reverso-reference.js
reverso-data.js
images/
   m-1931-original.jpg
   cal-410.jpg
   a-earhart.jpg
   ...
```

Every placeholder on the site prints its own slot ID in small
type underneath the icon — so you can read the name straight
off the page and save the file to match. Nothing else to change.

**Recommended:** ~1200px on the long edge, JPEG, under ~400 KB.
Models use a 4:5 portrait crop, archive pieces 1:1 square,
calibres a wide landscape strip.

## ⚠️ Read this before downloading anything

I could not download images for you — and you should be careful
about doing it in bulk yourself.

Photos on jaeger-lecoultre.com, Hodinkee, Revolution, SJX and
Monochrome are **copyrighted**, usually by the photographer or
the maison, not by the site. Using them on a public website is a
real infringement risk, however common the practice is.

Safer routes, roughly in order:

1. **Your own photographs.** Anything you shoot yourself is
   unambiguously yours. Best possible option for anything you own.
2. **Collector submissions.** Ask the owner for permission in
   writing when they submit — the form already collects an email.
3. **Ask Jaeger-LeCoultre press office** for a media kit. They
   generally do grant press/editorial use for enthusiast projects
   if you ask and credit properly. This is the correct route for
   current models and the Métiers Rares pieces.
4. **Auction house images** (Phillips, Christie's, Sotheby's,
   Artcurial). Often reusable for editorial/reference purposes
   with credit — but check each lot's terms.
5. **Wikimedia Commons / public domain** for historical context
   images (Amelia Earhart, Edward VIII, Balbo, polo scenes) —
   many of these are genuinely free to use with attribution.

Each entry already renders a **Source:** line where one exists,
so the attribution framework is in place.
